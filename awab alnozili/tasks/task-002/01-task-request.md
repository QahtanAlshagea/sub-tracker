## المخرجات المستهدفة
1. **نموذج إدارة الحالة لعرض الاشتراكات (`SubscriptionsViewState` & `SubscriptionsController`):** صياغة حالات العرض الأربع كصنف مختوم (`sealed class`) يمثل بدقة: `Loading`, `Empty`, `Data`, `Error` مع دعم إعادة المحاولة (`retry`).
2. **عناصر الواجهة المساعدة للحالات الأربع:**
   - شاشة/مكوّن التحميل الهيكلي (`LoadingShimmerView`).
   - شاشة/مكوّن الحالة الفارغة المصممة جذرياً مع زر الحث على الفعل (`EmptyStateView`).
   - شاشة/مكوّن حالة الخطأ مع رسالة عربية واضحة وزر إعادة المحاولة (`ErrorStateView`).
3. **مكوّن بطاقة الالتزام الدوري (`SubscriptionCard`):** بطاقة تفاعلية تعرض الاسم، السعر بالدورية، شارة الفئة بلونها وأيقونتها، ووسم الاستحقاق بالأيام المتبقية مع تمييز الحالات الحرجة ($\le 3$ أيام) والمتأخرة والتجارب المجانية، مع ضمان منطقة لمس $\ge 48\times 48$.
4. **لوحة ملخص المصروفات (`SummaryDashboard` / `SummaryCard`):** عرض الإجمالي الشهري المكافئ، التوقعات السنوية، عدد الاشتراكات النشطة، مع فصل العملات المتعددة بدقة.
5. **شاشة القائمة الرئيسية (`HomeScreen`):** التبديل السلس بين الحالات الأربع دون ظهور أي شاشة بيضاء فارغة، مع دعم التحديث بالسحب (`RefreshIndicator`) وزر الإضافة العائم.
6. **شاشة ونموذج إضافة وتعديل الاشتراك (`AddEditSubscriptionScreen`):** نموذج متكامل ومحكم بحقول الاسم (حتى 60 حرفاً)، السعر والعملة، الدورية (شهرية، سنوية، أسبوعية، مخصصة بالأيام)، التواريخ، الفئة، التجربة المجانية، الملاحظات، مع التحقق الدفاعي وظهور أخطاء الحقول في موضعها أسفل الحقل مباشرة وتأكيد الخروج عند وجود تعديلات غير محفوظة.
7. **منظومة اختبارات الواجهة (Widget Tests):** تغطية شاملة لكافة الحالات الأربع لكل شاشة ومكوّن، والتحقق من دعم RTL ومقياس الخط 200% ومساحات اللمس القياسية.
