# المكدس التقني والمكتبات (Technology Stack)
## المهندس: محمد العيدروس (Mohammed Al-Aidrous)

---

## 1. لغة البرمجة وإطار العمل
- **لغة البرمجة:** Dart 3.x (تفعيل النمط الصارم، Pattern Matching، Sealed Classes، و Null Safety الكاملة).
- **إطار العمل:** Flutter 3.x (القناة المستقرة Stable Channel).
- **المنصة المستهدفة الأساسية:** Android (العمل دون إنترنت 100% Offline-First).

---

## 2. محرك التخزين المحلي
- **قاعدة البيانات:** SQLite المضمنة محلياً عبر مكتبة **Drift** (سابقاً Moor).
- **وضع القفل والأداء:** تفعيل `PRAGMA journal_mode = WAL` لدعم القراءة المتزامنة دون حظر، و `PRAGMA foreign_keys = ON` لفرض التكامل المرجعي.
- **توليد الكود:** `drift_dev` و `build_runner` لإنشاء كود الـ DAOs والجداول والاستعلامات ذات الأنواع الآمنة (Type-Safe).

---

## 3. بيئة الاختبار وضمان الجودة
- **اختبارات الوحدة:** `package:test` و `flutter_test`.
- **البدائل المولدة (Mocks):** `package:mockito` مع توليد الكود الآلي.
- **جمع التغطية:** `package:coverage` وتوليد تقرير `lcov.info`.
- **التحليل الساكن:** `flutter_lints` مشدد مع تفعيل العلم الصارم `--fatal-infos` و `--fatal-warnings` لمنع أي تحذير.

---

## 4. أدوات التنسيق وإدارة المصدر
- **إدارة الإصدارات:** Git و GitHub مع حماية الفروع وتطبيق سير عمل Feature Branch و Conventional Commits.
- **التكامل المستمر:** GitHub Actions (`.github/workflows/ci.yml`) لتشغيل التنسيق الآلي، التحليل الصارم، فحص نقاء الدومين، واختبارات الوحدة والتغطية عند كل دفع أو طلب دمج.
- **إدارة المهام والتتبع:** لوحة كانبان على **Trello** لربط البطاقات بفرق العمل، ومصفوفة التتبع RTM.
