## مبادئ وضوابط العمل الهندسية

1. **نقاء طبقة الدومين 100% (Zero External Dependencies):** خلو تام من أي استيراد لـ Flutter أو Drift أو dart:io أو dart:ui.
2. **قاعدة الوحدات الصغرى للأموال (Minor Units Rule):** تخزين المبالغ المالية بأعداد صحيحة 64-بت وحظر الأعداد العشرية العائمة float/double.
3. **قاعدة تثبيت اليوم الأصلي (Original Anchor Day Rule):** منع الانزياح التراكمي في الشهور القصيرة والسنوات الكبيسة.
4. **التغطية الشاملة وحالات الحافة:** تغطية كل قاعدة عمل باختبارات حدّية تحمل معرّف الحالة `[EC-XX-Y]`.
5. **البرمجة الدفاعية:** عزل الاستثناءات بالكامل واستخدام النمط الوظيفي `Result<T>`.
