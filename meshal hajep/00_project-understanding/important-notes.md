## 1. بوابات الجودة الخمس الإلزامية (The 5 Quality Gates)

وفقاً لدليل الحوكمة الهندسية للمشروع (`docs/KANBAN_AND_GIT_WORKFLOW.md` و `GEMINI.md`)، لا يمكن اعتماد أي بطاقة أو دمج أي فرع إلا بعد اجتياز بوابات الجودة الخمس الصارمة:

1. **بوابة التحليل الساكن الصارم (Zero Analyzer Warnings Gate):**
   - التشغيل: `flutter analyze --fatal-infos`
   - النتيجة الإلزامية: صفر أخطاء، صفر تحذيرات، صفر تلميحات (Clean 100%).
2. **بوابة التنسيق القياسي (Format Compliance Gate):**
   - التشغيل: `dart format --set-exit-if-changed .`
   - النتيجة الإلزامية: تطابق كامل دون أي تعديلات متبقية.
3. **بوابة نقاء الدومين (Domain Purity Gate):**
   - الفحص: خلو مجلد `lib/**/domain/` تماماً من أي استيراد لمكتبات `Flutter` أو `Drift` أو `dart:io`.
4. **بوابة تغطية الاختبارات الآلية (Test Suite & Coverage Gate):**
   - التشغيل: `flutter test`
   - النتيجة الإلزامية: نجاح 100% لكافة الاختبارات (525 اختباراً ناجحاً حالياً).
   - نسب التغطية الدنيا: طبقة الدومين $\ge 85\%$ (المحقق: **96.63%**)، طبقة البيانات $\ge 70\%$ (المحقق: **79.14%**).
5. **بوابة الحالات الأربع للواجهة (4-ViewStates UI Gate):**
   - كل شاشة تفاعلية تختبر حالاتها الأربع الصريحة: `Data`, `Loading`, `Empty`, `Error with retry`.

## 2. المحاذير الأمنية والحدود غير القابلة للتفاوض (Stop Conditions)

بصفتي مهندس ضمان الجودة والأمان، يُحظر قبول أو دمج أي شيفرة تخالف القواعد التالية:
1. **حظر صلاحيات الإنترنت:** رفض أي محاولة لإضافة `android.permission.INTERNET` أو إدراج مكتبات سحابية خارجية (Firebase / Analytics / Ads) حفاظاً على خصوصية المستخدم المالية.
2. **حظر الأرقام العشرية للمال:** رفض استخدام `double` أو `float` في حسابات الدومين والكيانات وقاعدة البيانات، وحصر التعامل بالأعداد الصحيحة للوحدات الصغرى (`int`).
3. **حظر النصوص الواضحة لرمز PIN:** حظر تخزين أو تسجيل رمز PIN بصيغة نصية واضحة في الذاكرة الدائمة أو سجلات الطباعة (Console Logs).
4. **حظر الدمج المباشر:** يمنع الدفع المباشر على فرعي `develop` أو `main` دون مراجعة وطلب دمج (Pull Request) يمر عبر فحص CI الآلي.
