## 2. أدوات هندسة الاختبارات وضمان الجودة (QA Toolchain)

| الأداة / الحزمة | الغرض من الاستخدام | معايير النجاح والقبول |
|---|---|---|
| **flutter_test** | الإطار الأساسي لتشغيل اختبارات الوحدة والواجهة والمتحكمات. | اجتياز 525 اختباراً بنسبة نجاح 100% وبدون أي إخفاق. |
| **dart analyze** | التحليل الساكن الصارم للشيفرة المصدرية مع تفعيل خيار `--fatal-infos`. | 0 أخطاء، 0 تحذيرات، 0 معلومات (Clean 100%). |
| **dart format** | التحقق الآلي من مطابقة التنسيق القياسي للكود مع `--set-exit-if-changed`. | 0 فروقات تنسيق في كافة ملفات المشروع. |
| **coverage package** | جمع إحصائيات التغطية البرمجية وتوليد تقارير LCOV. | تغطية الدومين $\ge 85\%$ (المحقق 96.63%)، وتغطية البيانات $\ge 70\%$ (المحقق 79.14%). |
| **Fake Objects & Test Doubles** | محاكاة مستودعات البيانات لعزل طبقة الدومين ومنطق الأعمال تماماً. | استقلالية 100% للاختبارات وسرعة تنفيذ خارقة (< 15 ثانية لكامل الحزمة). |
| **GitHub Actions CI Pipeline** | خط الأنابيب المستمر المؤتمت للتحقق من بوابات الجودة عند كل Pull Request. | تشغيل حازم يمنع الدمج التلقائي عند رسوب أي فحص أو انخفاض التغطية. |

## 3. التدقيق الأمني وضمان عدم الاتصال (Offline & Security Audit)

- **غياب تصريح الإنترنت:** تم فحص ملف `android/app/src/main/AndroidManifest.xml` والتأكد القطعي من عدم وجود تصريح:
  ```xml
  <!-- غير موجود تماماً ومحظور وفق سياسة الخصوصية -->
  <uses-permission android:name="android.permission.INTERNET" />
  ```
- **تأمين التخزين المحلي لبيانات PIN:** التأكد من عدم تخزين رمز PIN بصيغة نصية واضحة في أي مكان، وتخزينه حصرياً كقيمة مجزأة رياضياً `sha256(pin + salt)`.
