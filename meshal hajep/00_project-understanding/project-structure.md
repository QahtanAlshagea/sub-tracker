## 1. الهيكل العام للمشروع

```text
sub-tracker/
├── .agents/                          # موجهات وقواعد الوكلاء الأذكياء ومصفوفة المهارات
├── .github/                          # تكوينات GitHub، قواعد المراجعة CODEOWNERS، وخط CI
├── docs/                             # الوثائق الهندسية المعتمدة (SRS, Architecture, Test Plan...)
├── img/                              # الأصول البصرية ومخططات تريلو وشعار الجامعة
├── lib/                              # الشيفرة المصدرية للتطبيق (Clean Architecture)
│   ├── core/                         # البنية التحتية المشتركة (Database, Services, Theme, Utils)
│   └── features/subscriptions/       # وحدة إدارة الالتزامات والدفعات الدورية
│       ├── domain/                   # طبقة النطاق (Pure Dart): الكيانات، حالات الاستخدام، العقود
│       ├── data/                     # طبقة البيانات: الجداول، كائنات DAOs، المستودعات، النماذج
│       └── presentation/             # طبقة العرض: الشاشات، الويدجات، ومتحكمات الحالة MVVM
├── test/                             # منظومة الاختبارات الشاملة (مسؤولية مشعل حاجب)
│   ├── unit/                         # اختبارات الوحدة (342 اختباراً)
│   │   ├── core/                     # اختبارات قاعدة البيانات، الهجرة، والإشعارات
│   │   └── features/subscriptions/
│   │       ├── domain/               # اختبارات الكيانات، القيم، وحالات الاستخدام
│   │       ├── data/                 # اختبارات الجداول، DAOs، ومصادر البيانات
│   │       └── presentation/         # اختبارات المنسقات الرياضية واللغوية
│   └── widget/                       # اختبارات الواجهة والمكونات (95 اختباراً)
│       ├── core/                     # اختبارات السمات والوصولية والتباين
│       └── features/subscriptions/presentation/
│           ├── screens/              # اختبارات الشاشات الـ 4 وحالاتها الأربع
│           └── widgets/              # اختبارات بطاقات الاشتراك وشريط التراجع
├── AI_Log.md                         # سجل قرارات الذكاء الاصطناعي والمراجعة البشرية
├── GEMINI.md                         # الدليل التأسيسي للمشروع ومحددات الوكلاء
└── README.md                         # الدليل العام للمستودع وتوزيع المسؤوليات
```

## 2. خريطة توزيع ملفات الاختبار ومسؤوليات الفحص (`/test/`)

| مسار ملفات الاختبار | نطاق المسؤولية البرمجية | نوع الفحص وحالات الحافة المغطاة |
|---|---|---|
| `test/unit/core/database/` | قاعدة بيانات Drift وترقية المخطط | فحص ترقية المخطط V1 إلى V2، الفهارس، والمعاملات الذرية. |
| `test/unit/core/services/` | خدمة الإشعارات المحلية | جدولة التنبيهات في الأوقات المحددة وإلغاؤها عند الحذف. |
| `test/unit/features/.../domain/entities/` | الكيانات ونماذج الحسابات | سلامة كائنات `Money`، الوحدات الصغرى، وفصل العملات المختلفة. |
| `test/unit/features/.../domain/validators/` | محركات التحقق والتقويم | تثبيت اليوم الأصلي `originalAnchorDay` وحساب التكرار $O(1)$. |
| `test/unit/features/.../domain/usecases/` | حالات الاستخدام الـ 16+ | تدفق العمليات بنمط `Result<T>` والتحقق من سياسات الإشعار. |
| `test/unit/features/.../data/daos/` | كائنات الوصول للبيانات DAOs | محاكاة انقطاع الطاقة والتراجع التلقائي (Rollback). |
| `test/unit/features/.../data/datasources/` | مصادر البيانات ومقاومة الأعطال | محاكاة قفل قاعدة البيانات، والتراجع وإعادة المحاولة. |
| `test/widget/features/.../screens/` | الشاشات الأربع ومتحكمات الحالة | الحالات الأربع (Loading, Data, Empty, Error) وتدوير الشاشة. |
| `test/widget/features/.../micro_interactions/` | التفاعلات الدقيقة واللمسية | التغذية الراجعة اللمسية، وشريط التراجع عن الحذف Undo SnackBar. |
