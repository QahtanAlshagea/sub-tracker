## 3. مبادئ وضوابط الجودة البرمجية المعتمدة (QA Directives)

1. **هرم الاختبارات الصارم (Test Pyramid):**
   - **اختبارات الوحدة (Unit Tests - 342 اختباراً):** فحص منطق الدومين الصرف، محركات الحسابات المالية، وقواعد التحقق بدون أي واجهة مستخدم أو محرك تخزين حقيقي.
   - **اختبارات البيانات والتخزين (Data/DAO Tests - 88 اختباراً):** التحقق من المعاملات الذرية، التراجع التلقائي (Rollback)، وتحويل أخطاء SQLite إلى كائنات Failure في الدومين.
   - **اختبارات الواجهة والمكونات (Widget Tests - 95 اختباراً):** اختبار تفاعل المستخدم، الحالات الأربع لكل شاشة (Data, Loading, Empty, Error)، التغذية اللمسية وشريط التراجع.
2. **تغطية حالات الحافة بنسبة 100%:** لا توجد حالة حافة واحدة في وثيقة قصص المستخدم (`docs/USER_STORIES.md`) إلا ولها اختبار يحمل معرّفها الصريح `[EC-XX-Y]`.
3. **صفر تسامح مع التحذيرات التحليلية:** خلو المشروع تماماً من أي تحذير في التحليل الساكن الصارم:
   ```bash
   flutter analyze --fatal-infos
   ```
4. **التوافق التام مع التنسيق القياسي:** خلو المشروع تماماً من أي اختلافات تنسيق:
   ```bash
   dart format --set-exit-if-changed .
   ```
5. **نقاء الدومين بنسبة 100% (Domain Purity):** التحقق الآلي من عدم استيراد أي مكتبة تخزين أو إطار عمل واجهة في مجلد الدومين.
